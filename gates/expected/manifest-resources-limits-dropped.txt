== resource manager limits ==
neutral -> hello from a resource set
culture-fr -> PlatformNotSupportedException: ResourceManager.GetString: a culture-specific lookup ('fr-FR') needs a satellite assembly, and AOT-compiled code links none — a satellite is a separate file the transpile never loaded, so 'not built' and 'unreachable' cannot be told apart here and answering the neutral string would be a silent wrong answer. Read the neutral resources (pass CultureInfo.InvariantCulture or use the no-culture overload), or localize through your engine's own translation system. Assembly 'ManifestResources' declares 'en-US' as its neutral culture, and that exact name is served from here too.
missing-set -> PlatformNotSupportedException: ResourceManager.GetString: the embedded manifest resources of assembly 'ManifestResources' were dropped at transpile time (--no-manifest-resources ManifestResources). Transpile without that flag, or keep the resource this read wants with '--manifest-resource-root <manifest name>'.
get-stream -> PlatformNotSupportedException: ResourceManager.GetStream returns an UnmanagedMemoryStream, whose body is not transpilable in AOT-compiled code. Read the resource through Assembly.GetManifestResourceStream(<BaseName>.resources), which hands back a read-only MemoryStream over the same bytes.
