# The cmake and ninja a toolchain bundle carries, so a user's machine needs
# neither. gates/setup-buildtools.sh reads this file and refuses an archive
# whose sha256 does not match.
# Rows: `archive <tool> <host> <url> <sha256> <strip>`.
#
# Full URLs rather than emsdk-pin.txt's base_url + path: cmake ships from
# Kitware's GitHub releases and ninja from ninja-build's, so one base would be a
# fiction. `strip` is the row's own archive root depth, which varies per row and
# cannot be inferred — cmake's macOS build roots two levels deeper than its
# others, and ninja's zips have no top-level directory at all.
#
# A cmake inside a forbidden_cmake band — half-open [first, past_last) — makes
# Emscripten's own CMake platform module build a SHARED library as a static
# archive, so the Web drop-in is never produced. The bands mirror
# CMakeVersionsWithoutWasmSharedLibs (the fork's Dn2CppExporter.cs), which
# refuses such a cmake: pinning into one would ship a cmake the bundle's own
# exporter rejects, on a user's machine.
