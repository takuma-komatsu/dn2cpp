# Open work

[GitHub Issues](https://github.com/takuma-komatsu/dn2cpp/issues?q=is%3Aissue%20is%3Aopen)
in `takuma-komatsu/dn2cpp` are the sole backlog for dn2cpp and its Godot editor
fork. This page is a stable entry point, not a second task list.

See [CONTRIBUTING.md](../CONTRIBUTING.md#what-to-work-on) for issue scope,
verification and completion rules, and [BUGFIX-WORKFLOW.md](BUGFIX-WORKFLOW.md)
for the explicitly requested continuous bug-fix workflow. Product boundaries
and durable implementation contracts remain in the repository documentation.
